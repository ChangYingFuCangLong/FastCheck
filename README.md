# 图书馆座位快速选座助手 · 使用说明

一份油猴脚本，电脑（Chrome/Edge）和安卓（Kiwi/Firefox 浏览器）通用。
作用：把你常坐的几个座位做成清单，一眼看完它们今天/明天的可约空窗，点一下空段就自动在官方页面选好**时段+座位**并**直接弹出官方安全验证界面**——**文字点选验证码永远由你本人完成**（脚本不代提交、不绕验证）。

## 一、安装

### 电脑端（Chrome / Edge）
1. 浏览器扩展商店安装 **Tampermonkey**（篡改猴）；
2. 打开 Tampermonkey → "添加新脚本"，把 `图书馆快速选座.user.js` 全部内容粘进去，Ctrl+S 保存；
   （或直接把 .user.js 文件拖进浏览器，Tampermonkey 会弹出安装页，点安装）
3. 从学校门户正常登录，进入"应用市场 → 座位预约"即可。

### 安卓端（推荐 Kiwi 浏览器）
1. 安装 **Kiwi Browser**（Chromium 内核，支持扩展）；
2. Kiwi 菜单 → 扩展 → 打开"开发者模式" → 从商店/扩展页安装 **Tampermonkey**；
3. Tampermonkey 里新建脚本，粘贴本文件内容并保存；
4. 在 Kiwi 里走学校门户登录 → 座位预约，右下角出现"⚡快速选座"即成功。
   （Firefox 安卓版也支持 Tampermonkey，步骤类似。）

> iOS 的 Safari 不支持油猴，暂不覆盖。

## 二、怎么用
1. 进入超星座位预约任意页面，点右下角 **⚡快速选座**；
2. 顶部切换 **今天 / 明天**（系统只开放提前 1 天预约）；
3. "至少"筛选目标时长（1–4h/不限），"排序"选最长优先或自己的顺序；
4. 每张卡片：座位号、楼层、状态、最长可约、迷你时间轴（**深绿≥4h，浅绿 1–4h，灰=已占/已过**）；
5. 点绿色空段：
   - 与当前官方页面**同房同天** → 当前页直接选好，**不刷新、不跳转**；
   - 不同房间/日期 → **不会自动刷新**，只提示你先从官方切到对应楼层/日期再点；
   - 空段 **4h 以内**直接预选；**超过 4h 自动拆成 2 段连约**（见下）；
6. 选好后脚本自动点官方"提交"并**弹出安全验证界面**（脚本面板会自动让开），**你本人完成文字点选验证**即预约成功。
7. 底部可随时"添加"座位，卡片右上角 × 移除；点"刷新"手动拉最新数据。

### 无电区分类（v1.4.8）
- 内置：**2F 阅览区 169–211 号为无电区**（官方接口无电源字段，按学校实际分区写死，两端含共 43 座）；
- 列表中每个楼层拆成"普通"与"· 无电区"两个小节，无电座位带灰色"无电"小标；高频卡上同样有标；
- 工具行"电源"下拉：**全部 / 仅有电 / 仅无电区**，选择会记住；
- 点"🔌无电区管理"可自己加无电座位：选楼层后输入座位号，支持 `172`、`172,175`、`172-175`（区间）三种写法，加入后排到该层无电小节，带**黄色**"无电"标；点黄色标签即可移除（内置灰标不可删），管理弹层里也能逐个 × 删除；
- 点无电座位弹时间块时，标题会带"· 无电区"。

### 门户一键直达（v1.4.7）
- 脚本同时匹配学校门户 os.hbcit.edu.cn（/index 与 /mobile）：登录门户后右下角出现"⚡ 座位预约 一键直达"，点一下直接进座位列表（CAS 单点登录自动放行，不用再点应用市场），落地后面板自动展开；
- 下面的"门户自动跳转：关/开"打开后，一进门户首页自动跳到座位预约（默认关，避免你办别的事时被带走；用 replace 跳转，返回键不会来回循环）；
- 门户与超星是两个域名，各自记住各自的开关；面板和取数仍只在超星座位页运行。

### 进入座位系统自动展开面板（v1.4.6）
- 默认开启：从门户进入"座位预约"列表页、或打开任一楼层座位图，快速选座面板会自动弹出，不用再点右下角按钮；
- 面板工具行有"🚀 进入自动展开：开/关"，关掉后恢复手动点"⚡快速选座"，选择会记住；
- 自动跨楼层续选的跳转落地页不弹面板，避免挡住验证。

### 点座位号选时间块（v1.4.5，手机端推荐，和官方时间选择一致）
点座位 → 弹"时间块"→ 点起止格 → 确认 → 直接到验证：
- **在快速面板里**点任意座位号/座位行，或**在官方座位图上直接点座位**，底部弹出该座位当天的**逐小时时间块**（和官方一样：白=可选、灰=已约/已过、蓝=起止、浅蓝=选中段）；
- 点一下**开始格**、再点**结束格**（整段高亮，可随时重点重选），底部按钮显示"确认预约 HH:MM-HH:MM"，点它即自动选好并弹官方验证；
- 顶部"快捷"行是脚本算好的整段空窗按钮，想快可一键选；
- 规则与官方完全对齐：只能从下一个整点开始、不能跨过已约格、单次最多4小时（超了自动收边，坐更久走分2段连约）；
- 点遮罩或 × 关闭；全程不刷新页面，验证码由本人点。
- v1.4.5 修复：点"确认预约"没反应的问题——当官方页面楼层/日期与所选不一致（如人在列表页、或面板选了明天而页面停在今天）时，脚本会自动跳到对应页面，落地后自动选好并弹验证；任何选不上的情况都会弹出明确原因，不再静默无反应。

### 早期"空段列表"方式（已被上面的时间块取代，保留说明）
**两种点选顺序都支持，全程不刷新页面，选好自动弹验证**：
- **顺序①（时间→座位）**：在官方底部时间弹窗点**开始块**和**结束块**，点完第二块自动确认，再点座位，验证界面自动弹出；
- **顺序②（座位→时间）**：先点你要的座位（蓝色描边=已记住），再点开始+结束时间块，时间确认后脚本自动把该座位选好并弹出验证；
- 只坐 1 小时：点一个时间块后，点右下角绿色浮钮"✔确认就坐这1小时"，再点座位即可；
- **↓到楼层**：面板底部下拉选楼层 → 点"↓到楼层"，**只在面板结果列表内滚动定位**到该楼层分区，不跳学校页面、不刷新；
- **◎定位**：输入座位号，该座位在官方图上蓝色闪烁 8 秒并自动滚到视野中央（只定位、不选座）；
- 验证界面弹出时脚本面板自动隐藏，关闭验证后自动恢复；"展开剩余 N 个"不会把列表滚回顶部；"⏱选时自动确认"可整体开关。

### 想坐超过 4 小时怎么办：分段连约（v1.3.0）
学校规则写死：**单次预约最多 4h、每天最多 2 次预约（即一天最多 8h）**，这是服务端硬限制，无法绕过。脚本的做法：
1. 直接点超过 4h 的空段（或"指定时段"选超过 4h，如 08:00–16:00），按钮上会标"·分2段"；
2. 脚本先把**第①段**（如 08:00–12:00）预选好，面板顶部出现蓝色"🔗分段连约"横幅；
3. 脚本自动弹出第 1 次安全验证，**你本人完成**（第①段预约提交）；
4. 回到选座页、打开面板，点横幅里的**【约第②段 12:00–16:00】**（这一步会刷新一次选座页，用于干净地选第②段），第②段预选好并自动弹验证；
5. **你本人**再提交+验证一次，两段首尾相连，同一个座位坐满 8h；
6. 若你选的总时长超过 8h（如 08:00–18:00），只规划前 8h 并明确提示"16:00 之后无法再约"；"取消连约"可随时清除计划。
> 注意：两段都必须本人各提交一次（各一次验证码），脚本不会代提交；第②段必须在第①段提交成功后再点。

### 面板怎么读（v1.3.0）
- **⭐ 高频座位**永远在最上面（你收藏的座位，符合条件的才显示）；
- 其后按 **2F 阅览区 → 2F·24h → 3F → 4F** 列出**全部空余座位**，每层默认显示前 40 个，点"展开剩余 N 个"看全；
- **指定时段**：工具栏第二行选"起 至 止"（如 08:00 至 12:00），列表只保留**能整段覆盖该时间**的座位；起始选"不限"则按"至少 N 小时"筛选；超过 4h 会提示自动拆 2 段；
- 点任意座位行/空段即**一键预选**（同房同天当前页直接选好、不刷新，选完自动弹验证；≤4h 直接选，>4h 走分段连约）；行尾 ☆ 可把该座加入高频；
- 高频卡片右上角 × 移除收藏。

### 添加高频座位的两种方式
- **手输**：面板底部选楼层 + 输入座位号 → 添加；
- **⭐点选添加（推荐，和官方界面一样）**：先进入某楼层的"选座"座位图，点面板上"⭐点选添加"开启模式，然后直接在官方座位图上点你看中的座位，即加入高频列表（**只收藏、不会触发预约**，已收藏座位有橙色描边）；再点一次该按钮退出，恢复正常选座。
- 说明：面板只显示"高频列表"里的座位，没添加过的楼层/座位不会出现；24h 借阅空间同理，进入它的座位图点选添加即可（该房间座位号为 001–117 补零格式，脚本已兼容）。

## 三、合规与安全说明（重要）
- 脚本**只调用只读查询接口**，不轮询抢座、不伪造验证码令牌、不绕过风控；脚本会替你点官方"提交"来**调出**安全验证界面，但**验证码与最终提交必须你本人完成**，脚本不碰 `/submit`；
- 数据只存在你本机浏览器（localStorage 收藏清单），不上传、不收集任何信息；
- 仅在你本人登录的官方页面运行，同源请求，自动带登录态，不需要输入账号密码；
- 请遵守图书馆预约规则：按时签到、暂离/退座、避免违约（每周违约 3 次停约本周）。

## 四、已知边界与维护
- 依赖超星官方页面结构与私有接口，官方改版后若失效，通常只需更新脚本里的"预选适配"部分；
- 从选好到你完成验证存在秒级竞争，若该座刚被约走，官方会报错，换一个空段即可；
- 会话过期时面板会提示从门户重新进入。
